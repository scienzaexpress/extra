# extra.scienzaexpress.it

Pagine di contenuti extra dei libri di Scienza Express edizioni, pubblicate con GitHub Pages.

| Percorso | Libro |
|---|---|
| `/astrofisici/` | Facciamo che eravamo astrofisici (M. Fumagalli, S. Colombo) |

L'indirizzo è stampato in un QR code nel libro: non va cambiato. Quando il sito della casa editrice sarà ripristinato, la pagina potrà essere spostata lì e questo indirizzo reindirizzato.
